## Section 2 — Typing Animation
**Location:** `app.py` — Lines 25–60

```python
const texts = ["Data Analyst", "SQL Developer", "Analytics Engineer",
               "Python Developer", "Data Engineer", "Business Analyst"];
```

**What to edit:**
- Add or remove job titles inside the `[ ]` list
- Each title must be in `"quotes"` and separated by commas
- `setTimeout(type, 1400)` → the pause between words (in milliseconds). Increase for slower, decrease for faster
- `setTimeout(type, 80)` → typing speed per letter. Increase = slower typing

## Section 3 — Navbar
**Location:** `app.py` — Lines 62–176

  ['Projects',       'projects'],
  ['Skills',         'skills'],

## Section 9 — Experience
**Location:** `app.py` — Lines 302–403

Each job card has this structure:

```html
<div class="exp-logo">S</div>              ← Single letter logo (first letter of company)

<div class="exp-role">Senior Executive — Data Analyst</div>   ← Job title
<div class="exp-sub-role">Founder's Office</div>              ← Department / team
<span class="exp-company">SAADAA</span>                       ← Company name
<span class="exp-type-badge">Full-time</span>                 ← Employment type

<div class="exp-date">May 2025 — Dec 2025</div>               ← Date range
<div class="exp-duration">8 months</div>                      ← Duration

<!-- Impact chips -->
<span class="chip-num">40%</span>
<span class="chip-label">Reporting Automated</span>           ← Impact metric

<!-- Bullet points -->
<li>Your achievement here</li>

<!-- Tool tags at bottom -->
<span>BigQuery</span><span>SQL</span>
```

**What to edit:**
- **Job title:** edit `exp-role` text
- **Department:** edit `exp-sub-role` text
- **Company name:** edit `exp-company` text and the logo letter `<div class="exp-logo">S</div>`
- **Dates:** edit `exp-date` and `exp-duration`
- **Impact chips:** change the numbers and labels in `chip-num` / `chip-label`
- **Bullets:** edit or add `<li>` items inside `<ul class="exp-points">`
- **Tools:** add/remove `<span>ToolName</span>` items in `exp-tools-row`

**To add a new job:** Copy the entire `<div class="exp-card">...</div>` block and paste it above or below, then edit all the content inside.

**To change job card color** (currently Job 1 = blue, Job 2 = purple):
- The accent bar color is set inline: `style="background:linear-gradient(to bottom,#a855f7,...)"`
- The logo color is also inline: `style="background:rgba(168,85,247,0.12);color:#a855f7;..."`
- Replace `#a855f7` with any hex color you want

## Section 11 — Skills Graph
**Location:** `app.py` — Lines 506–571

### Node colors
```python
colors = {
    "center": "#1E293B",   ← Center node (My Expertise) — dark grey
    "tech":   "#3B82F6",   ← Technical nodes — blue
    "biz":    "#A855F7",   ← Business nodes — purple
    "soft":   "#10B981",   ← Professional nodes — green
    "ai":     "#F59E0B",   ← AI Tools nodes — orange/yellow
    "vis":    "#4206cf"    ← Visualization nodes — dark blue/indigo
}
```

### Adding a new skill node
```python
# Add to nodes list:
Node(id="Spark", label="Apache Spark", size=45, shape="circle",
     color=colors["tech"], font={"size": 8, "color": "white"}),

# Add to edges list to connect it:
Edge(source="T", target="Spark"),   # connects to Technical parent
```

### Changing node size
- `size=80` → center node (biggest)
- `size=60` → category nodes (Technical, Business, etc.)
- `size=45` → skill nodes (Python, SQL, etc.)

### Skill Tags (below the graph)
```python
tags = [
    "Data Analyst", "Python", "SQL", ...   ← Add or remove tags here
]
```
Just add a new string inside the list: `"Apache Spark"` — it will appear as a pill tag.

## Section 15 — Floating Action Bar (FAB)
**Location:** `app.py` — Lines 701 onwards (inside `components.html`)

The FAB has 4 buttons. Here's where each lives in the JS code:

### Theme Toggle Button
```javascript
themeBtn.innerHTML = '☀️';                    ← Icon when in dark mode
themeBtn.setAttribute('data-tip', 'Light Mode'); ← Tooltip text
// After click (switches to light):
themeBtn.innerHTML = '🌙';
themeBtn.setAttribute('data-tip', 'Dark Mode');
```

### Back to Top Button
```javascript
topBtn.innerHTML = '↑';                        ← Arrow character
topBtn.setAttribute('data-tip', 'Back to Top'); ← Tooltip text
```

### Resume Download Button
```javascript
resumeBtn.innerHTML = '📄';                    ← Icon emoji
resumeBtn.setAttribute('data-tip', 'Download Resume');
resumeBtn.download = 'Mann_Choudhary_Resume.pdf'; ← Downloaded filename
```
Note: The actual PDF file is read from `assets/resume.pdf` at the top of app.py.

### LinkedIn Button
```javascript
liBtn.href = 'https://www.linkedin.com/in/mann-choudhary-data-analyst'; ← Your LinkedIn URL
liBtn.setAttribute('data-tip', 'LinkedIn');
```

**To change button position:** find `.fab-bar` in the JS styles:
```css
bottom: 28px;   ← Distance from bottom of screen
right: 24px;    ← Distance from right edge of screen
```

**To change button size:** find `.fab-btn`:
```css
width: 46px;
height: 46px;
```

## CSS Quick Reference (style.css)

| What you want to change | Search for in style.css |
|---|---|
| Page background color | `background-color: #020617` |
| Default text color | `color: #e2e8f0` |
| Blue accent color used everywhere | `#3b82f6` |
| Font families | `@import url(...)` at top of file |
| Section heading size | `.section-title` |
| Card background color | `.exp-card`, `.proj-card`, `.cert-card` |
| Metrics bar grid | `.metrics` |
| Skill tag pills | `.tag` |
| Contact card layout | `.contact-grid`, `.contact-card` |
| Mobile breakpoints | `@media (max-width: 680px)` at bottom |

### Color Palette Used

| Color | Hex | Used for |
|---|---|---|
| Page background | `#020617` | Main dark background |
| Card background | `#0b162c` | All cards |
| Blue accent | `#3b82f6` | Borders, buttons, highlights |
| Light blue text | `#60a5fa` | Company names, numbers |
| Body text | `#cbd5e1` | Bullet points, descriptions |
| Muted text | `#64748b` | Dates, labels, subtitles |
| Green | `#10b981` | Open to Work badge, Completed status |
| Purple | `#a855f7` | Business nodes, Job 2 accent |
